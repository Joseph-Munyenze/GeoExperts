4. Backups

A backup is saved automatically before every change (the latest 50 are kept). Restoring also backs up the current state first, so it can be undone.

Field guide

Column names are not case-sensitive. Any of the names in the second column work, so files exported from QGIS, ArcGIS, Google Earth or Google My Maps can be uploaded as they are. In KML, put fields in ExtendedData; the placemark name and description are read too.
