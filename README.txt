HOW TO HOST THIS WEBSITE
========================
This folder is a complete static website. index.html must stay at the top
level, next to the css, js and images folders.

Option A - Free, fastest (Netlify Drop)
  1. Unzip this file.
  2. Go to https://app.netlify.com/drop and drag the unzipped folder in.
  3. The site is live at once; add your own domain under Domain settings.

Option B - Paid web hosting with cPanel (e.g. a .co.ke domain host)
  1. In cPanel open File Manager > public_html.
  2. Upload this zip, then Extract it there.
  3. Check that index.html sits directly inside public_html.

Option C - GitHub Pages / Cloudflare Pages
  Upload these files to a repository (index.html at the root) and turn on
  Pages for that repository.

Editing later
  Text:    index.html
  Colours: css/style.css (top lines)
  Photos:  replace files in images/ keeping the same file names

Note: the contact form opens the visitor's email app with the message
filled in. It needs no server, so it works on any host.
